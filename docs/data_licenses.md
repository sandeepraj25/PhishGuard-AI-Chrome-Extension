# Data and feed licences

Checked on 2026-10-20 from the sources linked below. Terms change — **re-check every source before a commercial launch** (listed in HUMAN_TODO). This is not legal advice.

| Source | Used for | What the terms say (paraphrased) | Commercial use? | Action |
|---|---|---|---|---|
| **OpenPhish community feed** | Phishing URLs (training, feed worker) | The public feed repository marks the community feed as non-commercial only and points to OpenPhish's Terms of Use. Paid feeds (Premium/Premium Plus/Platinum) are annual subscriptions. [1][2] | **No (blocks commercial use)** | `backend/config/feeds.json` marks it `commercialUseAllowed: false`; `COMMERCIAL_MODE=true` skips it. Buy a commercial feed (set `OPENPHISH_PREMIUM_URL`) or drop it. |
| **PhishTank** (Cisco Talos) | Phishing URLs with `submission_time` | FAQ: free for everyone; API may be used for commercial and non-commercial purposes; free registration gives an app key; hourly request limits apply. The FAQ does not state redistribution or attribution terms. [3] | Yes per FAQ | Read the full terms/developer page for redistribution rules before shipping derived lists in the extension. Needs `PHISHTANK_APP_KEY`. |
| **Tranco list** | Legitimate domains | The site does not state a licence for the list itself. Its attribution section lists upstream sources and their licences, including Cloudflare Radar under **CC BY-NC 4.0** (non-commercial) and Majestic under CC BY 3.0. A third-party project describes Tranco as MIT, but we could not confirm that on tranco-list.eu. [4][5] | **Unclear — flag** | The default list blends a CC BY-NC source. For commercial use, generate a custom Tranco list without Cloudflare Radar, or ask the Tranco maintainers in writing. |
| **Public Suffix List** | Registered-domain logic (`shared/public_suffix_list.dat`) | Mozilla Public License 2.0 (header of the file). | Yes (MPL file-level copyleft: keep the file's notice; modifications to that file must be shared) | `shared/psl_overrides.txt` is a separate file; keep the PSL notice. |
| **Unicode confusables (UTS #39)** | Homoglyph map (`ml/scripts/build_confusables.py --confusables`) | Unicode License v3 (permissive, keep notice). Not downloaded in this build; the bundled map is a curated subset + NFKD folding. | Yes | Add the Unicode licence text to `shared/` when you regenerate with the full file. |
| **Certificate Transparency logs** (v2) | New-domain discovery | Public append-only logs; no licence restriction, but each log operator has usage/rate policies. | Yes | Respect per-log rate limits (configured in the CT worker). |
| **RDAP** (registries via IANA bootstrap, rdap.org) | Domain age | Each registry has its own terms and rate limits; bulk harvesting is often prohibited. | Generally yes for low-volume lookups | Cache 30 days, batch of 20/min, only for domains already in our system. |
| **ONNX Runtime Web** | Inference | MIT licence | Yes | Ship its licence in the store package (`THIRD_PARTY_NOTICES`). |
| **LightGBM** | Training | MIT licence | Yes | — |
| **Our synthetic sample** | Pipeline tests | Generated by `ml/scripts/make_sample_data.py` | Yes | Not real data; never quote its metrics. |

## Blocking issues for a commercial launch

1. **OpenPhish community feed** is non-commercial → license a paid feed or remove it.
2. **Tranco default list** includes CC BY-NC data → build a custom list or get written permission.
3. **PhishTank redistribution**: shipping a Bloom filter derived from PhishTank inside the extension is redistribution of derived data — confirm it is allowed.
